# 需求/设计视觉确认（数据驱动，禁止自由发挥）

把 spec/plan 里**已经声明**的设计，用可看的 HTML 画出来，让用户在写代码前确认"结构对不对、产出长什么样、哪里要改"。**核心纪律：只画 spec/plan 里声明了的，绝不凭感觉补充**——缺失的部分输出"待定义"清单，而不是 AI 自己编。

## 前置条件
- 当前功能目录：`specs/<编号>-<功能名>/`，其中要有：
  - `plan.md`（含架构分层/模块/技术栈/数据流）→ 供「架构总览.html」
  - `spec.md`（含**报告区块 / 输出契约 / 数据契约**字段）→ 供「效果演示.html」
- 缺 plan.md → 先跑 `$speckit-cn-plan`；缺 spec.md → 先跑 `$speckit-cn-specify`。

## 关键约束（这条是防"凭感觉"的红线）
- **只渲染 spec/plan 中显式声明的区块/字段/模块**，逐条映射到 HTML 结构。
- spec/plan 里**没有声明报告区块 / 数据契约** → `效果演示.html` **不生成**，改为输出一份「区块待定义清单」（列出 spec 该补哪些区块定义），并提示用户先补 `$speckit-cn-clarify`。**禁止 AI 自己给 report 设计区块。**
- 架构页同理：plan 没写清某层模块/依赖 → 标「（待定义）」，不补写。
- 所有示例数值必须标注「示例/示意」，且用明显不同于真实分析的标识（如标题脚注、数据源标签"示例数据"）。
- **previews/ 只是看稿，不是产品**：确认后它不进入任何开发链路，不被重构/复用为正式产品；正式产品由 `$speckit-cn-implement` 按 `plan` 声明的技术栈（Python/Streamlit/React/报告生成器……）另行实现，与 previews/ 无关。

## 步骤

### 1. 定位并读取
- 确定当前功能目录（当前分支 / `SPECIFY_FEATURE` 环境变量 / 最新一个 `specs/` 子目录）。
- 读 `plan.md` 与 `spec.md`。用 python 解析出以下两类"声明的结构"：
  - **架构结构**：分层、每层模块、依赖方向、数据流、技术栈（从 plan 提取）
  - **报告/输出结构**：报告包含哪些区块、每区块的字段/图表/内容定义（从 spec 提取）

### 2. 检查缺口
- 缺失区块/字段 → 收集，按上面红线处理（架构页标待定义；效果页则整体不生成+出待定义清单）。
- 全齐 → 进入生成。

### 3. 生成 2 份自包含静态 HTML（Write 工具写，UTF-8，放 `项目根/previews/`）
- **`架构总览.html`**：分层模块图 + 模块分组卡片 + 箭头依赖 + 技术栈 + 核心数据流。只画 plan 声明的；未明说处标「（待定义）」。
- **`效果演示.html`**：按 spec 声明的**报告区块顺序**逐块 mock——概览指标卡、各图表（ECharts）、话术列表、人群画像、策略卡等。每个区块都必须能对应回 spec 里那一条字段定义；数值一律示例并标注。**若 spec 未声明区块则不生成本页**（见第 2 步）。
- 技术要求：单文件、可双击打开；ECharts 用 CDN `https://cdn.jsdelivr.net/npm/echarts@5.4.3/dist/echarts.min.js`（若要离线可改为内联 vendor）；样式仿照产品视觉（卡片/标签/配色），但不写任何业务逻辑。

### 4. 输出"区块↔spec"映射表
- 打印：每个 HTML 区块 ← 对应 spec/plan 的哪一条声明（证明是数据驱动，不是瞎画）。
- 若无映射可展示（即缺口）→ 打印「待定义清单」。

### 5. 报告并发回（给用户看的）
- 两份 HTML 的**绝对路径**（可点击）。
- 待定义清单（若有）。
- 明确提示：**确认通过前，不得进入 `$speckit-cn-tasks` / `$speckit-cn-implement`。** 用户反馈"哪里不对" → 回写 spec/plan → 重新运行本 skill 重新生成预览。

## 本机执行约定
1. 生成 HTML / 解析数据结构用 python（读 utf-8）；**不允许** AI 在头脑里编造结构再画——结构必须来自读到的 spec/plan 文本。
2. 涉及 PowerShell 一律 `python {{ZCODE_DIR}}/scripts/silent.py powershell -NoProfile -ExecutionPolicy Bypass -File <脚本> [参数]`。
3. 路径含中文/空格 → python `subprocess.run(list)`，不做字符串拼接。
